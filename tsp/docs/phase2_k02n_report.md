# Phase 2 ablation: test graph k = 0.2 n (Joshi et al. 2021) vs. k = 0.5 n and k = 10

Generated by `scripts/phase2_k02n_report.py` on 2026-10-27.

**In one line: our 0.5 n is better than or equal to Joshi's 0.2 n, never worse** — better with 2-opt at n = 50–100 (5 of 8 tests, by 0.3–0.6 pp) and much better without 2-opt up to n = 200 (3–5 pp; uncapped 0.5 n also at 500–1000 in 6 of 8 tests, by 2–3 pp), equal with 2-opt from n = 200 on (at n = 1000 our capped k = 100 is below 0.2 n = 200, still n.s.); k = 10 is the worst at every n ≥ 100.

**Automatic verdict (with 2-opt, k = min(0.5 n, 100) vs. 0.2 n, per size):** n = 50: mixed (3 better, 0 worse, 1 n.s. of 4); n = 100: mixed (2 better, 0 worse, 2 n.s. of 4); n = 200: equal; n = 500: equal; n = 1000: equal.

Nothing was retrained: the TAGCN K=3 and GCN models of phases 1–2 (TSP-20, k = 10, best.pt, seeds 0–2) are evaluated with `scripts/scale_eval.py` on TSP-50 to TSP-1000. Only the network's test graph changes between columns; the 2-opt always uses the neighbour lists of min(0.5 n, 100), so the k = min(0.5 n, 100) column is the existing phase 2 scale result (reproduced exactly on tsp200 before launching). Our k is capped at 100, so at n = 500 it equals 0.2 n, and at n = 1000 it is below 0.2 n; the uncapped 0.5 n was run at 500 and 1000.
