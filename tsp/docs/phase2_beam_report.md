# Phase 2 — beam search decoding

Generated by `scripts/phase2_beam_report.py` on 2026-10-19.
No model was retrained: the same edge probabilities are decoded with greedy and with beam search (B = 10, 100), each without and with 2-opt (2-opt is applied to the tour that beam search returns). Test graphs: k = 0.5 n (k = 10 on TSP-20, 25 on TSP-50, 50 on TSP-100). Seeds 0, 1, 2.

Beam search (`tsp_gnn.decode.beam_search_decode`) works on the same edge choices as greedy: a partial solution is a set of accepted edges; it is extended by one valid edge at a time, partial solutions are ranked by the sum of the log-probabilities of their edges (pairs outside the graph: log 1e-12), duplicate edge sets are removed, and the B best are kept. At the end the shortest of the B tours is returned (selection by length, as in Joshi et al. 2019). With B = 1 it is exactly greedy. It is *pure* beam search: the greedy tour can be pruned from the beam, so on some instances beam search is worse than greedy (Table 4).
